Featured build

Making sense of a 300-page conference program

A web app built with Claude and Claude Code that reads a medical conference program book (PDF) and turns it into an overview, charts of the main themes, presenters and institutions, and a searchable list you can export as your own agenda PDF. Visitors use their own Anthropic API key, or try a free demo.

Use the app →

The part I'll remember: before trusting the AI, we measured it, the same way we'd validate a new lab test. This third project had far more real coding structure than the first two, and I learned it by doing the same steps over and over.

Earlier builds

Tracking industry payments to pediatric society leadership

A public dashboard built with Claude and Claude Code, tracking CMS Open Payments (Sunshine Act) data for the officers and boards of national pediatric subspecialty societies — general, research, and combined totals, broken out by organization and by year.

View the dashboard →

I hadn't written code since BASIC on an Apple IIe in 1989 — vague memories of moving a triangle around the screen and figuring out how to make the background flash across the color spectrum. This project was a real test of how far I could get by describing what I wanted to Claude, rather than writing it myself.
