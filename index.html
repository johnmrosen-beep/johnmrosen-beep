Featured build

Tracking industry payments to pediatric society leadership

A public dashboard built with Claude and Claude Code, tracking CMS Open Payments (Sunshine Act) data for the officers and boards of national pediatric subspecialty societies — general, research, and combined totals, broken out by organization and by year.

View the dashboard →

I hadn't written code since BASIC on an Apple IIe in 1989 — vague memories of moving a triangle around the screen and figuring out how to make the background flash across the color spectrum. This project was a real test of how far I could get by describing what I wanted to Claude, rather than writing it myself.

Latest build

Modeling clinic scheduling strategy for a pediatric GI practice

An interactive tool built with Claude and Claude Code for modeling professional RVU production across clinic templates — built to help my division think through scheduling strategy under a new practice plan, using real CMS billing rules instead of guesswork.

Use the tool →

The most interesting part wasn't the coding — it was discovering that our own clinic template couldn't actually support some of the visit codes we assumed we were billing, once the time thresholds were laid out precisely.
